# ペア対話用スピーキングテスト

会話で承認済みの仕様：スピーキングテスト配下に「教師との対話・スピーチ用」「ペア対話用」を表示する。横向き画面を左右に二分割し、別々の児童・生徒を選択する。左右それぞれの上部で役割1・役割2を切り替え、両役割の評価を個人ごとに保持する。役割名、評価内容・段階・基準は任意設定とし、Unit・表現は固定しない。

方式：既存画面への二人分の拡張と専用画面を比較し、利用者は専用画面追加を選択。作成・一覧・クラス選択・バックアップ・出力の仕組みは共用する。既存テストは教師との対話・スピーチ用として扱う。

実装上の判断：各項目に role1 / role2 を付け、既存の個人別結果内に両役割の項目を保存する。左右で同じ児童を選べないようにする。入力時に保存し、未評価・途中・完了を区別する。保存済み結果は評価時の項目・役割名を保持する。

追加要件：返却資料は評価項目ごとに表示し、評価内容の先頭に【役割１】【役割２】を付ける。作成者が役割名を設定した場合は【お店屋さん】等の設定名を使用する。個票と項目別の得点一覧に適用する。
